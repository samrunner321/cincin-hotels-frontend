# CinCin Hotels - Next.js Frontend

Luxury hotel collection platform built with Next.js 14 and Directus CMS.

## Quick Start

```bash
npm install
npm run dev
```

## Environment Setup

1. Copy `.env.example` to `.env.local`
2. Configure your Directus URL and tokens
3. Set up your database connection

## Deployment

### Vercel
1. Connect your repository
2. Set environment variables in Vercel dashboard
3. Deploy

### VPS
1. Set up Directus instance
2. Configure production environment variables
3. Run `npm run build && npm run start`

- Next.js 14 (App Router)
